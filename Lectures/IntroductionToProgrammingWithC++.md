 ## Η συνάρτηση `main` και η εκτέλεση εντολών στη C++

Το πρόγραμμα μας αρχίζει να εκτελείται από τη συνάρτηση `main`. Για αρχή, οτιδήποτε θέλουμε να κάνει το πρόγραμμά μας θα το γράφουμε μέσα στα άγκιστρα (`{}`) της `main`. Το τι ακριβώς υποδηλώνουν τα άγκιστρα θα το δούμε στη συνέχεια.

Ο υπολογιστής εκτελεί τις εντολές εκτός της `main` από πάνω προς τα κάτω. Στον παρακάτω κώδικα για παράδειγμα, πρώτα θα εκτελεστεί η εντολή `cout << "Let's start";`, και στη συνέχεια, η  `return 0;`.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() 
{
    cout << "Let's start!";
    return 0;
}
```
Ποια η λειτουργία του προγράμματος που μόλις γράψαμε; Η πρώτη εντολή εντός της `main` τυπώνει στην οθόνη τη φράση Let's start. Η εντολή `cout` αποτελεί τον συνήθη τρόπο να γράφουμε στην οθόνη. Η σύνταξή της έχει ως εξής. 

```cpp
cout << κάτι << κάτι άλλο << ... ; 
```

Στην προκειμένη περίπτωση, τυπώσαμε στην οθόνη ένα μικρού μήκους κείμενο. Παρατηρήστε ότι εσωκλείσαμε τη φράση μέσα σε `""`, κανόνας που θα ακολουθούμε κάθε φορά που θέλουμε να γράψουμε κείμενο στην οθόνη.

Η επόμενη σε σειρά εντολή λέει στον υπολογιστή να τερματίσει την εκτέλεση του προγράμματος. Προσέξτε 
ότι κάθε φορά που τελειώνει μία εντολή προσθέτουμε τον χαρακτήρα `;`.

Δεν μιλήσαμε ακόμα για τις δύο εντολές στην αρχή του κώδικα. Η πρώτη εκ των δύο συμπεριλαμβάνει στο πρόγραμμα μία βιβλιοθήκη. 
Μια βιβλιοθήκη είναι μια συλλογή έτοιμων τμημάτων κώδικα, τα οποία μπορούμε να χρησιμοποιούμε στα προγράμματά μας χωρίς να χρειάζεται να τα υλοποιούμε από την αρχή.

Για παράδειγμα, η εντολή `cout` μάς επιτρέπει να εμφανίζουμε πληροφορίες στην οθόνη με απλό τρόπο, χωρίς να χρειάζεται να γνωρίζουμε τις εσωτερικές λεπτομέρειες της υλοποίησής της.

Η υλοποίηση της `cout` παρέχεται από τη βιβλιοθήκη της C++, η οποία περιλαμβάνεται μέσω της οδηγίας `#include <bits/stdc++.h>`.

Ένα **namespace** είναι ένας τρόπος να οργανώνουμε ονόματα στον κώδικά μας, ώστε να ξεχωρίζουμε σε ποια ομάδα ανήκει το καθένα.

Για παράδειγμα, στη C++ υπάρχει το namespace `std`, το οποίο περιέχει ονόματα που χρησιμοποιούμε συχνά, όπως το `cout`.

Όταν γράφουμε `std::cout`, το `std::` δηλώνει ότι το `cout` ανήκει στο namespace `std`.

Έτσι, μπορούμε να εμφανίσουμε ένα μήνυμα στην οθόνη γράφοντας:

```cpp
std::cout << "Let's start!";
```

## Μεταβλητές και τύποι δεδομένων

Στον προγραμματισμό, πολλές φορές χρειάζεται να αποθηκεύουμε πληροφορίες, όπως αριθμούς, δεκαδικούς αριθμούς ή κείμενο, ώστε να μπορούμε να τις χρησιμοποιούμε αργότερα στο πρόγραμμά μας.

Για τον σκοπό αυτό, χρησιμοποιούμε τις **μεταβλητές**.

Μια μεταβλητή είναι ένας χώρος (κουτάκι) στη μνήμη του υπολογιστή στον οποίο αποθηκεύουμε μια τιμή. Κάθε μεταβλητή έχει ένα όνομα, μέσω του οποίου μπορούμε να αναφερόμαστε σε αυτήν, και έναν **τύπο δεδομένων**, ο οποίος καθορίζει τι είδους τιμές μπορεί να αποθηκεύσει.

Για παράδειγμα, στη C++ μπορούμε να δημιουργήσουμε τη μεταβλητή $x$, στην οποία αναθέτουμε την τιμή $5$.
```cpp
int x = 5;
```

Μπορούμε να φανταστούμε τη μνήμη του υπολογιστή ως ένα δισδιάστατο πλέγμα από κουτάκια, καθένα από τα οποία αντιστοιχεί σε μια θέση μνήμης. Με την παραπάνω δήλωση, ο υπολογιστής δεσμεύει μια θέση μνήμης, της αποδίδει το όνομα $x$ και της αναθέτει την τιμή $5$. Όσο η μεταβλητή $x$ παραμένει ενεργή και η θέση μνήμης της εξακολουθεί να είναι δεσμευμένη για αυτήν, κάθε μεταβολή της τιμής της μεταβλητής ενημερώνει την αντίστοιχη θέση μνήμης.

### Βασικοί τύποι δεδομένων στη C++

Στη C++, υπάρχουν διάφοροι τύποι δεδομένων, οι οποίοι μας επιτρέπουν να αποθηκεύουμε διαφορετικά είδη πληροφοριών.

Οι βασικότεροι είναι οι εξής:

- **`int`**: Χρησιμοποιείται για την αποθήκευση ακέραιων αριθμών, όπως το `5`, το `18` και το `-10`.
- **`double`**: Χρησιμοποιείται για την αποθήκευση αριθμών με δεκαδικά ψηφία, όπως το `3.14` και το `2.5`.
- **`char`**: Χρησιμοποιείται για την αποθήκευση ενός χαρακτήρα, όπως το `'A'`, το `'b'` ή το `'7'`. Ο χαρακτήρας γράφεται μέσα σε μονά εισαγωγικά.
- **`string`**: Χρησιμοποιείται για την αποθήκευση κειμένου, όπως το `"Hello World!"` ή το `"Καλημέρα"`. Το κείμενο γράφεται μέσα σε διπλά εισαγωγικά.
- **`bool`**: Χρησιμοποιείται για την αποθήκευση μιας λογικής τιμής, η οποία μπορεί να είναι `true` (αληθής) ή `false` (ψευδής).

### Παραδείγματα

```cpp
int age = 18;
double height = 1.75;
char grade = 'A';
string name = "Maria";
bool isStudent = true;
```

## Εισαγωγή δεδομένων με την `cin`

Ενώ η εντολή `cout` μάς επιτρέπει να εμφανίζουμε πληροφορίες στην οθόνη, η εντολή `cin` μάς επιτρέπει να **διαβάζουμε δεδομένα που εισάγει ο χρήστης** μέσω του πληκτρολογίου.

Για να διαβάσουμε την τιμή του $x$ γράφουμε
```cpp
cin >> x;
```

Όπως και με τη cout μπορούμε να διαβάσουμε πολλές μεταβλητές στην ίδια γραμμή. Για παράδειγμα,
```cpp
int x, y, z;
cin >> x >> y >> z;
```

## Τελεστές στη C++

Οι τελεστές (operators) είναι σύμβολα που χρησιμοποιούνται για να εκτελούμε πράξεις, να συγκρίνουμε τιμές και να ελέγχουμε συνθήκες.

### 1. Αριθμητικοί τελεστές

Χρησιμοποιούνται για μαθηματικές πράξεις.

| Τελεστής | Πράξη | Παράδειγμα | Αποτέλεσμα |
|---|---|---|---|
| `+` | Πρόσθεση | `5 + 3` | `8` |
| `-` | Αφαίρεση | `5 - 3` | `2` |
| `*` | Πολλαπλασιασμός | `5 * 3` | `15` |
| `/` | Διαίρεση | `6 / 3` | `2` |
| `%` | Υπόλοιπο διαίρεσης | `7 % 3` | `1` |

**Προσοχή στη διαίρεση:** Όταν διαιρούμε δύο ακέραιους αριθμούς (`int`), το δεκαδικό μέρος απορρίπτεται.
```cpp
cout << 7 / 2;  // 3.
```
Δύο τρόποι για να λύσουμε το πρόβλημα
- Οποιοδήποτε αριθμό χρησιμοποιούμε τον δηλώνουμε ως πραγματικό (κακή πρακτική).
- Χρησιμοποιούμε **casting**.

Το casting τη στιγμή που γίνεται η πράξη μετατρέπει τον αριθμό στον τύπο που επιθυμούμε. Στο παράδειγμα παρακάτω μετατρέποντας έναν από τους δύο σε `double` μας δίνει το αναμενόμενο αποτέλεσμα.

```cpp
cout << (double)7 / 2; // 3.5.
```


### Τελεστές ανάθεσης στη C++

Οι τελεστές ανάθεσης χρησιμοποιούνται για να δίνουμε τιμές σε μεταβλητές ή να αλλάζουμε τις υπάρχουσες τιμές τους.

### 1. Απλή ανάθεση (`=`)

Ο τελεστής `=` χρησιμοποιείται για να αναθέσουμε μια τιμή σε μια μεταβλητή.

```cpp
int x = 10;
```

Σε αυτό το παράδειγμα, η μεταβλητή `x` παίρνει την τιμή `10`.

Μπορούμε επίσης να χρησιμοποιήσουμε την υπάρχουσα τιμή μιας μεταβλητής για να υπολογίσουμε μια νέα τιμή και να την αποθηκεύσουμε ξανά στην ίδια μεταβλητή.

```cpp
int x = 10;
x = x + 5;
```

Σε αυτή την περίπτωση, η διαδικασία γίνεται σε δύο βήματα:

1. Υπολογίζεται πρώτα η δεξιά πλευρά της ισότητας. Η υπάρχουσα τιμή του `x`, δηλαδή το `10`, προστίθεται με το `5`, οπότε το αποτέλεσμα είναι `15`.
2. Το αποτέλεσμα `15` ανατίθεται στη μεταβλητή `x`, αντικαθιστώντας την προηγούμενη τιμή της.

Επομένως, στο τέλος η μεταβλητή `x` έχει τη νέα τιμή `15`.

**Σημαντικό:** Στη C++, το `x = x + 5` δεν είναι μαθηματική ισότητα. Είναι μια εντολή που υπολογίζει μια νέα τιμή και την αποθηκεύει στη μεταβλητή `x`.

### 2. Σύντομοι τελεστές ανάθεσης

Η C++ προσφέρει συντομογραφίες για εκφράσεις όπως η `x = x + 5;`.

Για παράδειγμα, η έκφραση:

```cpp
x += 5;
```

είναι ισοδύναμη με την:

```cpp
x = x + 5;
```

Ο τελεστής `+=` προσθέτει το `5` στην υπάρχουσα τιμή της μεταβλητής `x` και αποθηκεύει το αποτέλεσμα ξανά στην ίδια μεταβλητή.

Αν το `x` έχει αρχικά την τιμή `10`, μετά την εκτέλεση της εντολής `x += 5;` θα έχει την τιμή `15`.

Εκτός από τον `+=`, οποιοσδήποτε τελεστής που αριθμητικός τελεστής μπορεί να γραφεί κατ' αυτόν τον τρόπο.

### 3. Τελεστές σύγκρισης

Χρησιμοποιούνται για να συγκρίνουμε δύο τιμές. Το αποτέλεσμα είναι `true` (αληθές) ή `false` (ψευδές).

| Τελεστής | Σημασία |
|---|---|
| `==` | Ίσο με |
| `!=` | Διαφορετικό από |
| `>` | Μεγαλύτερο από |
| `<` | Μικρότερο από |
| `>=` | Μεγαλύτερο ή ίσο με |
| `<=` | Μικρότερο ή ίσο με |

### Παράδειγμα

```cpp
int a = 5;
int b = 10;
```

Οι τελεστές σύγκρισης συγκρίνουν δύο τιμές και επιστρέφουν `1` αν η συνθήκη είναι αληθής ή `0` αν είναι ψευδής.

```cpp
a == b  // 0, επειδή το 5 δεν είναι ίσο με το 10.
a != b  // 1, επειδή το 5 είναι διαφορετικό από το 10.
a < b   // 1, επειδή το 5 είναι μικρότερο από το 10.
a > b   // 0, επειδή το 5 δεν είναι μεγαλύτερο από το 10.
a <= b  // 1, επειδή το 5 είναι μικρότερο ή ίσο με το 10.
a >= b  // 0, επειδή το 5 δεν είναι μεγαλύτερο ή ίσο με το 10.
```

Στη C++, όταν εμφανίζουμε μια τιμή `bool` με την `cout`, το `true` εμφανίζεται ως `1` και το `false` ως `0`, εκτός αν έχει ενεργοποιηθεί διαφορετική μορφοποίηση.

### Λογικοί τελεστές στη C++

Οι λογικοί τελεστές χρησιμοποιούνται για να συνδυάζουμε ή να αντιστρέφουμε λογικές συνθήκες. Το αποτέλεσμα μιας λογικής έκφρασης είναι `true` (αληθές) ή `false` (ψευδές).

### 1. Ο τελεστής `&&` (ΚΑΙ)

Ο τελεστής `&&` επιστρέφει `true` μόνο όταν **και οι δύο συνθήκες είναι αληθείς**. Αν έστω και μία είναι ψευδής, το αποτέλεσμα είναι `false`.

| Συνθήκη 1 | Συνθήκη 2 | Αποτέλεσμα |
|---|---|---|
| `true` | `true` | `true` |
| `true` | `false` | `false` |
| `false` | `true` | `false` |
| `false` | `false` | `false` |

Παραδείγματα:

```cpp
(5 > 3 && 10 > 7) // true.
(5 > 3 && 10 < 7) // false.
(5 < 3 && 10 > 7) // false.
(5 < 3 && 10 < 7) // false.
```

### 2. Ο τελεστής `||` (Ή)

Ο τελεστής `||` επιστρέφει `true` όταν **τουλάχιστον μία από τις δύο συνθήκες είναι αληθής**. Επιστρέφει `false` μόνο όταν και οι δύο συνθήκες είναι ψευδείς.

| Συνθήκη 1 | Συνθήκη 2 | Αποτέλεσμα |
|---|---|---|
| `true` | `true` | `true` |
| `true` | `false` | `true` |
| `false` | `true` | `true` |
| `false` | `false` | `false` |

Παραδείγματα:

```cpp
(5 > 3 || 10 > 7) // true.
(5 > 3 || 10 < 7) // true.
(5 < 3 || 10 > 7) // true.
(5 < 3 || 10 < 7) // false.
```

### 3. Ο τελεστής `!` (ΟΧΙ)

Ο τελεστής `!` αντιστρέφει μια λογική τιμή:

- Αν η τιμή είναι `true`, γίνεται `false`.
- Αν η τιμή είναι `false`, γίνεται `true`.

| Λογική έκφραση | Αποτέλεσμα |
|---|---|
| `!(5 > 3)` | `false` |
| `!(5 < 3)` | `true` |
| `!(10 == 10)` | `false` |
| `!(10 != 10)` | `true` |

### Συνοψίζοντας

- `&&` σημαίνει **ΚΑΙ**: όλες οι συνθήκες πρέπει να είναι αληθείς.
- `||` σημαίνει **Ή**: τουλάχιστον μία συνθήκη πρέπει να είναι αληθής.
- `!` σημαίνει **ΟΧΙ**: αντιστρέφει το αποτέλεσμα μιας λογικής έκφρασης.

### Προαύξηση και μετααύξηση

Υπάρχει διαφορά ανάμεσα στις μορφές `++x` και `x++` όταν χρησιμοποιούνται μέσα σε εκφράσεις.

- `++x`: πρώτα αυξάνεται η μεταβλητή και μετά χρησιμοποιείται η νέα τιμή.
- `x++`: πρώτα χρησιμοποιείται η αρχική τιμή και μετά αυξάνεται η μεταβλητή.

```cpp
int x = 5;
int a = ++x;

// x = 6.
// a = 6.
```

```cpp
int x = 5;
int a = x++;

// a = 5.
// x = 6.
```

Η ίδια διάκριση ισχύει και για τους τελεστές μείωσης `--x` και `x--`.

## 9. Προτεραιότητα τελεστών

Όταν έχουμε πράξεις μεταξύ αριθμητικών τελεστών ισχύει η προτεραιότητα που ισχύει στα μαθηματικά. 

```cpp
int resultOne = 2 + 3 * 4;
cout << resultOne; // 14.

int resultTwo = (2 + 3) * 4;

cout << resultTwo; // 20.
```

### Προτεραιότητα τελεστών στις λογικές εκφράσεις

Όταν μια λογική έκφραση περιέχει περισσότερους από έναν τελεστές, η C++ ακολουθεί συγκεκριμένη σειρά προτεραιότητας.

Η σειρά προτεραιότητας των τελεστών που χρησιμοποιούμε στις λογικές εκφράσεις είναι:

| Προτεραιότητα | Τελεστής | Σημασία |
|---|---|---|
| 1η | `!` | ΟΧΙ |
| 2η | `<`, `>`, `<=`, `>=` | Σύγκριση |
| 3η | `==`, `!=` | Ισότητα και ανισότητα |
| 4η | `&&` | ΚΑΙ |
| 5η | `\|\|` | Ή |

**Παράδειγμα**

```cpp
5 > 3 && 10 < 7 || 4 == 4
```

Η έκφραση υπολογίζεται με την εξής σειρά:

1. `5 > 3` → `true`
2. `10 < 7` → `false`
3. `4 == 4` → `true`
4. `true && false` → `false`
5. `false || true` → `true`

**Σημαντικό:** Οι τελεστές σύγκρισης έχουν μεγαλύτερη προτεραιότητα από τους `&&` και `||`. Επίσης, ο `&&` έχει μεγαλύτερη προτεραιότητα από τον `||`.

Μπορούμε να χρησιμοποιούμε παρενθέσεις `()` για να καθορίζουμε με σαφήνεια τη σειρά υπολογισμού μιας λογικής έκφρασης.
